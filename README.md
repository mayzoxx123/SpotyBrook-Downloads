# 🎵 SpotyBrook

**SpotyBrook** est un lecteur de musique Spotify pour Windows, avec un mode One Piece, le statut Discord et une télécommande sur téléphone.

##  Télécharger

👉 [**Télécharger la dernière version**](https://github.com/mayzoxx123/SpotyBrook-Downloads/releases/latest)

##  Fonctionnalités

- Lecteur à pochettes avec carrousel
- Mode One Piece avec transitions et fonds
- Statut Discord
- Télécommande sur téléphone
- Playlists ajoutables par lien
- Mini-lecteur Windows (Win + J)

## 🛠️ Installation

1. Télécharge `SpotyBrook_Setup_v328.14.exe`.
2. Double-clique dessus.
3. Si Windows affiche « Windows a protégé votre ordinateur », clique sur **Informations complémentaires**, puis **Exécuter quand même**.
4. Laisse l'installation se terminer : SpotyBrook s'ouvre tout seul.

Une connexion internet est nécessaire pendant l'installation.
